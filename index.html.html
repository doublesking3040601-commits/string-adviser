String Adviser プライバシーポリシー

最終更新日：2026年9月3日

String Adviser（以下「本アプリ」）は、ユーザーのプライバシー保護を重要視しています。 本プライバシーポリシーは、本アプリにおける情報の取り扱いについて説明するものです。

1. 取得する情報

本アプリは、ユーザーの氏名、住所、メールアドレス、 電話番号その他の個人情報を取得しません。

2. 利用する情報

本アプリでは、ユーザーが選択したラケットやガットの条件をもとに、 推薦結果を表示します。

これらの入力情報は端末内でのみ処理され、 開発者や第三者へ送信されることはありません。

3. 第三者への提供

本アプリは、取得した情報を第三者へ提供しません。

4. アクセス解析

本アプリは、現時点でアクセス解析サービスを利用していません。

5. 広告について

本アプリは、現時点で広告配信サービスを利用していません。

将来的に広告サービスを導入する場合は、 本プライバシーポリシーを更新し、その内容を公開します。

6. 外部サービス

本アプリは、ユーザー情報を収集する外部サービスとは連携していません。

7. プライバシーポリシーの変更

本ポリシーは必要に応じて変更されることがあります。

更新後の内容は、本ページに掲載された時点から有効となります。

8. お問い合わせ

本アプリに関するお問い合わせは、 開発者までお願いいたします。
